# AgentPay — 1-minute pitch script

**0:00-0:12**

Hi, we're AgentPay. AI agents today need a fast, machine-native way to pay each other for APIs, data, and compute, but humans and credit cards get in the way.

> こんにちは、AgentPayです。AIエージェントは、APIやデータ、計算リソースの支払いを即座に行う機械同士の手段が必要ですが、人間の承認やクレジットカードが障害になっています。

**0:12-0:27**

AgentPay solves this with a simple 402-style payment check added to any HTTP endpoint, so any API can require payment before responding.

> AgentPayはこれを解決します。どんなHTTPエンドポイントにも402形式のシンプルな支払いチェックを追加し、支払いがあって初めて応答するようにします。

**0:27-0:42**

When one agent calls another, its wallet automatically signs a tiny USDC micropayment using Solana Pay, and the response comes back instantly, no human approval needed.

> あるエージェントが別のエージェントを呼び出すと、そのウォレットが自動的にSolana Payを使って少額のUSDC決済に署名し、人間の承認なしで即座に応答が返ってきます。

**0:42-0:52**

Our live dashboard visualizes these agent-to-agent payments in real time, and policy-based spending limits keep every wallet safe from overspending.

> ライブダッシュボードはエージェント間の支払いをリアルタイムで可視化し、ポリシーに基づく支出制限が各ウォレットを安全に保ちます。

**0:52-1:00**

AgentPay is built on Solana, ready to power the growing agent economy. Thank you.

> AgentPayはSolana上に構築されており、拡大するエージェント経済を支える準備ができています。ありがとうございました。
